# Anurag Vishwakarma — Portfolio (rebuild v2)

Fresh rebuild on branch `rebuild-v2-base`. Stack (user-decided):

- **Next.js** (App Router) + **TypeScript**
- **SCSS** (sass) — no Tailwind
- **GSAP** — animation
- **Three.js** + **@react-three/fiber** + **@react-three/drei** — 3D character (Part 3)
- **Lenis** — smooth scrolling
- **lucide-react** — icons

## Run

```bash
npm install
npm run dev   # http://localhost:3000
npm run build # production build check
```

## Parts

- Part 2 (this branch): base setup — preloader (Vikas Patel style), header with
  script wordmark logo, hero shell with placeholder panel for the 3D character.
- Part 3: 3D character (MoncyDev-style technique, built fresh).
- Later parts: content sections (About, Projects, Journey, Contact).
